The upstream MIT license is reproduced verbatim in LICENSE and packaged at

Horizon (https://github.com/horizon-rust/horizon), at the November 18 revision
0b14f8acfd97fa2c750e42795249dcc981178ca4, is LGPL-3.0-or-later. Older code
remains available under its original MIT terms; Horizon's LICENSES directory
contains those notices. Horizon Mixins (https://github.com/horizon-rust/horizon-mixins)
is an MIT-licensed developer tool. Neither is included in the .hmod.

The optional Windows game ZIP includes the modified Horizon executable under
LGPL-3.0-or-later, its license, GPL text and Horizon's third-party notices.
The same release's corresponding-source archive includes the exact transformed
Horizon source, all locked Cargo dependency sources with their license files,
and offline build/relink instructions. No private signing key is needed.
Spatial GUI's original MIT license remains in effect for its own code.

This bundle contains no Mojang game code or assets. Prepared resources must
come from the player's own Minecraft installation through Horizon.
